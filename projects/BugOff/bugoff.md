## Overview

**Bug Off!** Bug off! is a tower defense meets survivors-like shooter 
game where you defend your base against hordes of alien insects using the power of your mech and turrets you build.

It was made by a team of 6 students from the **Łódź University of Technology**.
The game was a submission to ZTGK 2025 in Game Development category. 

It was awarded **1st place** in the category and received special awards for **Best Audio** as well as awards from:
- Activision / Elsewhere Entertainment
- Game Access Conference

The game features a variety of turrets to choose from, 
each with 2 possible upgrades path, yielding a total of 16 unique upgrades! 
Player can build fortifications and support buildings as well. 

Vampire-survivors-like nature of the game allows the player to unlock powerful upgrades, 
including things like secondary weapons, active abilities and stat boosts.

The game was made using a custom-build engine, using DirectX 12 (hence, windows only). 
You can find out more about the engine at https://github.com/wojtek-kowalczyk/bug-off-game.

You can download the game on [itch.io](https://wolnyzolw.itch.io/bug-off).

My responsibilities in the project included:
- 2D Physics Engine with collision detection, resolution and ray/circle casting
- Audio Manager with FMOD C++ API integration
- UI system
- Unity-like editor made with ImGui
- Various smaller systems like ecs, cvar system, input-handling, windowing, etc.
- Gameplay programming
- Sound effects
- Music composition with adaptive music system in FMOD
